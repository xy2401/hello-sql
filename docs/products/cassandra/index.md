# Apache Cassandra 总览

Apache Cassandra 是一款去中心化、高可用、高写入吞吐的分布式宽列（Wide-Column）NoSQL 数据库系统，专为海量时序、日志与高吞吐写入场景设计。

## 适用边界

按访问模式设计分区键，适合分布式写入与键范围读取；CQL 不提供关系库式任意 JOIN，跨分区查询需单独设计。
