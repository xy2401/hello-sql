# MariaDB 版本演进

> **版本模型**：社区版并行维护长期支持、滚动和开发版本线；生产应固定明确的长期支持系列。

## 版本发布规律与生命周期

- **发布策略**：社区版并行维护长期支持、滚动和开发版本线；生产应固定明确的长期支持系列。
- **官方权威发布说明**：[查看 MariaDB 官方 Release Notes ↗](https://mariadb.com/docs/release-notes)

## 主流版本线与关键特性

### MariaDB 11.8 LTS

**关键功能与演进：**

- 面向长期维护的稳定系列
- 需核对从 10.x/11.4 的参数和插件差异

**工程影响与选型建议：**

> 新生产部署优先从 LTS 系列评估。

### MariaDB 11.4 LTS

**关键功能与演进：**

- 成熟的长期支持基线
- 生态兼容通常比快速版本更充分

**工程影响与选型建议：**

> 既有平台可按支持周期决定是否迁往 11.8。

### MariaDB 12.x 滚动/开发线

**关键功能与演进：**

- 更快引入优化器和 SQL 能力
- 兼容与回退成本更高

**工程影响与选型建议：**

> 用于前瞻验证，不要把开发版本当作默认生产基线。

## 生产升级检查清单

跨版本或主版本升级时，建议按顺序核对以下事项：

1. **执行 mariadb-upgrade 并核对系统表**
2. **验证存储引擎、Galera 和备份插件**
3. **对比 MySQL 客户端、SQL mode 与 GTID 行为**

::: warning 官方依据声明
补丁号、生命周期支持期限（EOL）、预览功能和许可协议会随时间演进。生产环境变更前，请始终以 [MariaDB 官方发布说明](https://mariadb.com/docs/release-notes) 为最终依据，勿仅凭文档标题推断当前最新版本。
:::
