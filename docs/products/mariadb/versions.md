# MariaDB 版本演进

MariaDB 社区版维护 5 年长期支持版（LTS）与按季度的滚动发布版本。

## 核心版本演进与关键里程碑

### MariaDB 11.4 LTS（2024 年 5 月）

**主要功能与架构演进：**

- 当前最新的长期支持版本，提供至 2029 年的官方维护
- 优化了成本优化器模型（Cost-based Optimizer）对复杂复合索引的选择策略
- 增强 Galera Cluster 同步复制认证吞吐

**工程影响与选型建议：**

> 新上线 MariaDB 系统的首选推荐版本。

### MariaDB 10.11 LTS（2023 年 2 月）

**主要功能与架构演进：**

- 企业级成熟 LTS 基准版本，广泛支持于主流 Linux 发行版
- 全面提升 InnoDB 脏页刷盘与临时表处理性能

**工程影响与选型建议：**

> 当前部署最为广泛的稳定版。

### MariaDB 10.6 LTS（2021 年 7 月）

**主要功能与架构演进：**

- 原生内置原子 DDL 改进与兼容 Oracle 语法的 PL/SQL 增强
- 支持针对 JSON 字段的更多快捷操作符

**工程影响与选型建议：**

> 企业异构数据库迁移的重要跳板。

### MariaDB 10.5（2020 年 6 月）

**主要功能与架构演进：**

- 全面重构 S3 存储引擎（允许将归档表直接存储于 AWS S3）
- ColumnStore 列式分析引擎深度融合进主干发行版

**工程影响与选型建议：**

> 具备混合事务与分析（HTAP）能力的早期版本。

## 升级实战
```bash
# 升级包安装后必须运行系统表升级
mariadb-upgrade -u root -p
```
