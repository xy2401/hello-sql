# MariaDB 核心知识

## 核心机制深入

### 1. 多存储引擎在业务中的针对性组合

- **Aria 存储引擎**：用于系统临时表与只读字典表，在发生意外停电时无需全表扫描即可自动恢复，比 MyISAM 更加安全。
- **ColumnStore**：将 MariaDB 转换为实时分析（HTAP）架构，支持对海量明细数据做列式压缩与向量化扫描。

### 2. Galera Cluster 的认证冲突机制

- Galera 采用基于写集合（Write-set）的乐观并发控制：
  - 本地节点执行事务时不向远端加锁。
  - 在事务 `COMMIT` 时，写集合广播至所有节点进行全局认证（Certification）。
  - 若两个节点并发更新同一行，先到达认证阶段的成功，后到达的直接报死锁并强制回滚。
