# Valkey 版本演进

> **版本模型**：提供 7.2、8.x、9.x 等并行版本线；主版本可能引入新能力，补丁版本集中安全与缺陷修复。

## 版本发布规律与生命周期

- **发布策略**：提供 7.2、8.x、9.x 等并行版本线；主版本可能引入新能力，补丁版本集中安全与缺陷修复。
- **官方权威发布说明**：[查看 Valkey 官方 Release Notes ↗](https://valkey.io/download/releases/)

## 主流版本线与关键特性

### Valkey 9.1

**关键功能与演进：**

- 最新功能版本线
- 需要较新的客户端与工具验证

**工程影响与选型建议：**

> 适合新能力验证，生产采用要核对生态支持。

### Valkey 9.0

**关键功能与演进：**

- 9.x 主版本基线
- 与 8.x 的配置和命令变化需检查

**工程影响与选型建议：**

> 升级前回放命令、脚本和持久化文件。

### Valkey 8.1/8.0

**关键功能与演进：**

- 生态较成熟的版本线
- 仍持续获得补丁更新

**工程影响与选型建议：**

> 从 Redis OSS 迁移通常先以此类成熟线做验证。

## 生产升级检查清单

跨版本或主版本升级时，建议按顺序核对以下事项：

1. **比较 COMMAND 输出与脚本依赖**
2. **验证 RDB/AOF、模块和客户端**
3. **演练复制、Cluster 与回滚**

::: warning 官方依据声明
补丁号、生命周期支持期限（EOL）、预览功能和许可协议会随时间演进。生产环境变更前，请始终以 [Valkey 官方发布说明](https://valkey.io/download/releases/) 为最终依据，勿仅凭文档标题推断当前最新版本。
:::
