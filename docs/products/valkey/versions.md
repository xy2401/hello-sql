# Valkey 版本演进

Valkey 在 Linux 基金会公开透明治理下推进，兼顾 Redis 7.2 开源协议兼容与性能创新。

## 核心版本演进与关键里程碑

### Valkey 8.0（2024 年 9 月）

**主要功能与架构演进：**

- 引入优化的多线程 I/O 与事件调度，在保持单命令原子性的同时吞吐量比 Redis 7.2 提升高达 20%~30%
- 异步集群槽位迁移（Async Slot Migration），显著降低大规模 Resharding 时的客户端延迟抖动
- 内存字典重新紧凑化，空闲与高频修改内存开销进一步降低

**工程影响与选型建议：**

> 当前高性能自建内存缓存与集群的首选版本。

### Valkey 7.2（2024 年 4 月）

**主要功能与架构演进：**

- 基于 Redis 7.2.4 开源基线构建的首个官方发布版本
- 100% 保持 RESP2/RESP3 协议、RDB 快照、AOF 日志与已有客户端驱动的完全兼容

**工程影响与选型建议：**

> 从 Redis 7.2 开源版无缝切换至 Valkey 的稳定桥梁。

## 迁移验证
- 直接使用既有 `redis.conf`（重命名为 `valkey.conf`）并加载既有 RDB 快照即可完成原地平滑迁移。
