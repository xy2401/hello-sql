# Valkey 8.0

> **参考官方文档**：[Valkey 官方发布说明](https://github.com/valkey-io/valkey/releases)  
> 本页依据正式 Release 与现有仓库版本证据，整理 Valkey 8.0 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2024 年 9 月
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** Valkey

## 核心变化

**主要功能与架构演进：**

- 引入优化的多线程 I/O 与事件调度，在保持单命令原子性的同时吞吐量比 Redis 7.2 提升高达 20%~30%
- 异步集群槽位迁移（Async Slot Migration），显著降低大规模 Resharding 时的客户端延迟抖动
- 内存字典重新紧凑化，空闲与高频修改内存开销进一步降低

**工程影响与选型建议：**

> 当前高性能自建内存缓存与集群的首选版本。

## 兼容与迁移

- 先完成备份、恢复演练和官方升级预检，不跨越未受支持的中间版本。
- 在副本、分片或集群环境按官方顺序滚动升级，并监控复制、延迟和错误日志。
- 同步核对客户端驱动、扩展、认证、配置参数与存储格式；回滚能力必须在升级前验证。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
valkey-server --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
