# Valkey 版本演进

Valkey 在 Linux 基金会公开透明治理下推进，兼顾 Redis 7.2 开源协议兼容与性能创新。

## 版本索引

### [Valkey 9.1](./valkey-9.1)

- **发布时间：** 2026 年
- **版本重点：** 截至核对日的当前正式功能版本线。

### [Valkey 8.0](./valkey-8.0)

- **发布时间：** 2024 年 9 月
- **版本重点：** 引入优化的多线程 I/O 与事件调度，在保持单命令原子性的同时吞吐量比 Redis 7.2 提升高达 20%~30%。

### [Valkey 7.2](./valkey-7.2)

- **发布时间：** 2024 年 4 月
- **版本重点：** 基于 Redis 7.2.4 开源基线构建的首个官方发布版本。

## 迁移验证
- 直接使用既有 `redis.conf`（重命名为 `valkey.conf`）并加载既有 RDB 快照即可完成原地平滑迁移。
