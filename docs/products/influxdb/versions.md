# InfluxDB 版本演进

InfluxDB 经历了从 1.x -> 2.x -> 3.x 三代截然不同的架构重构，代际之间通常作为数据迁移工程推进。

## 核心版本演进与关键里程碑

### InfluxDB 3.0 (IOx)（2023 年 4 月）

**主要功能与架构演进：**

- 全新基于 Rust 开发的 Apache Arrow、DataFusion 与 Parquet 存储执行内核
- 彻底消除高基数（High Cardinality）序列爆炸痛点，无限扩展 Tag 数量
- 全面回归标准 SQL 查询，原生支持将数据持久化在对象存储（S3）中

**工程影响与选型建议：**

> 时序数据库底层架构的革命性重构。

### InfluxDB 2.0（2020 年 11 月）

**主要功能与架构演进：**

- 引入 Flux 函数式脚本查询语言与统一的 Bucket/Token 权限模型
- 将 UI 控制台、后台调度任务与数据收集整合为单二进制包

**工程影响与选型建议：**

> 一体化时序分析平台，适合中等规模且依赖 Flux 复杂变换的场景。

### InfluxDB 1.8（2020 年 4 月）

**主要功能与架构演进：**

- 1.x 系列成熟稳定版，以 InfluxQL 与 Database/Retention Policy 为核心
- 提供向 2.x 升级的数据导出与兼容层

**工程影响与选型建议：**

> 经典老系统的稳定基线。

## 代际迁移建议
- 1.x/2.x 迁往 3.0 需重新评估查询语句（由 InfluxQL/Flux 转换为标准 SQL），并使用专用的迁移同步工具。
