# TiDB 8.5 LTS

> **参考官方文档**：[TiDB 官方发布说明](https://docs.pingcap.com/tidb/stable/release-8.5.0/)  
> 本页依据正式 Release 与现有仓库版本证据，整理 TiDB 8.5 LTS 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2024 年 12 月
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** TiDB

## 核心变化

- 汇总 8.2–8.4 DMR 的性能、稳定性和可观测性改进
- 成为继 8.1 后的新长期支持线
- 面向金融等低延迟负载继续优化数据处理路径

## 兼容与迁移

- 按官方 LTS 到 LTS 路径升级，先检查 TiDB、TiKV、PD、TiFlash 与工具链版本矩阵，再完成回滚演练。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
tidb-server -V
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
