# TiDB 版本演进

TiDB 交替提供 LTS（长期支持版）与 DMR（开发里程碑版），生产推荐选用支持期内的 LTS 版本。

## 核心版本演进与关键里程碑

### TiDB 8.1 LTS（2024 年 5 月）

**主要功能与架构演进：**

- 增强的资源管控（Resource Control）：支持基于用户组设置 CPU/IOPS 限制与排队
- TiFlash 向量化加速与列存多数据中心副本部署优化
- 分布式执行计划绑定（SPM）更具稳定性

**工程影响与选型建议：**

> 当前生产大规模部署与混合负载推荐版本。

### TiDB 7.5 LTS（2023 年 12 月）

**主要功能与架构演进：**

- 引入资源组（Resource Groups）与 RU（Request Unit）计量模型，实现多租户资源物理隔离
- 优化分布式死锁检测器与大事务悲观锁吞吐

**工程影响与选型建议：**

> 多业务共享 TiDB 集群的核心里程碑。

### TiDB 7.1 LTS（2023 年 5 月）

**主要功能与架构演进：**

- 支持分区表动态裁剪与重构分布式事务延迟
- TiKV 引入细粒度 RocksDB 内存配额控制

**工程影响与选型建议：**

> 大规模分区数据查询性能大幅提升。

### TiDB 6.5 LTS（2022 年 11 月）

**主要功能与架构演进：**

- 正式确立成熟的企业级 PITR（时间点恢复）与冷备份加速
- 引入基于规则的表达式索引与缓存优化

**工程影响与选型建议：**

> 金融级容灾与备份恢复基线。

## 滚动升级
- 使用 **TiUP** 工具包执行集群拓扑检查与逐组件（PD -> TiKV -> TiFlash -> TiDB）滚动升级：
  ```bash
  tiup cluster upgrade <cluster-name> v8.1.0
  ```
