# TiDB 版本演进

> **版本模型**：TiDB 交替提供 LTS 与开发里程碑（DMR）；生产通常选择仍在支持期的 LTS。

## 版本发布规律与生命周期

- **发布策略**：TiDB 交替提供 LTS 与开发里程碑（DMR）；生产通常选择仍在支持期的 LTS。
- **官方权威发布说明**：[查看 TiDB 官方 Release Notes ↗](https://docs.pingcap.com/releases/tidb-self-managed/)

## 主流版本线与关键特性

### TiDB 8.5 LTS

**关键功能与演进：**

- 8.x 能力沉淀为长期支持线
- 组件必须遵守兼容矩阵

**工程影响与选型建议：**

> 新生产集群的重点评估基线。

### TiDB 8.1 LTS

**关键功能与演进：**

- 较早的 8.x 长期支持线
- 迁往 8.5 需关注计划与系统变量

**工程影响与选型建议：**

> 既有集群按支持周期和收益决定升级。

### TiDB 7.5 LTS

**关键功能与演进：**

- 成熟 7.x 基线
- 跨 8.x 可能出现优化器和行为变化

**工程影响与选型建议：**

> 先在克隆流量上比较执行计划。

## 生产升级检查清单

跨版本或主版本升级时，建议按顺序核对以下事项：

1. **使用 TiUP 检查组件和拓扑**
2. **备份并演练 BR 恢复**
3. **回放慢查询、DDL、大事务与 TiFlash 计划**

::: warning 官方依据声明
补丁号、生命周期支持期限（EOL）、预览功能和许可协议会随时间演进。生产环境变更前，请始终以 [TiDB 官方发布说明](https://docs.pingcap.com/releases/tidb-self-managed/) 为最终依据，勿仅凭文档标题推断当前最新版本。
:::
