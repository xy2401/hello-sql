# DuckDB 版本演进

> **版本模型**：遵循语义化版本；较大功能进入 minor，patch 主要修复。从 1.4 起交替提供 LTS 系列。

## 版本发布规律与生命周期

- **发布策略**：遵循语义化版本；较大功能进入 minor，patch 主要修复。从 1.4 起交替提供 LTS 系列。
- **官方权威发布说明**：[查看 DuckDB 官方 Release Notes ↗](https://duckdb.org/release_calendar)

## 主流版本线与关键特性

### DuckDB 1.5

**关键功能与演进：**

- 继续扩展分析 SQL、文件与性能能力
- 文件格式和扩展兼容需按发布说明核对

**工程影响与选型建议：**

> 升级嵌入式绑定时同时更新扩展。

### DuckDB 1.4 LTS

**关键功能与演进：**

- 首批明确 LTS 版本线
- 适合需要较稳定维护窗口的嵌入式生产

**工程影响与选型建议：**

> 生产基线优先评估 LTS，而不是无条件跟随最新 minor。

### DuckDB 1.0+

**关键功能与演进：**

- 稳定存储格式和 API 进入成熟阶段
- WASM 与本地客户端能力并非完全一致

**工程影响与选型建议：**

> 浏览器端单独验证线程、内存和文件 API。

## 生产升级检查清单

跨版本或主版本升级时，建议按顺序核对以下事项：

1. **备份数据库文件并测试向前/向后读取**
2. **核对扩展仓库与客户端绑定版本**
3. **回归浮点、排序和非确定性查询**

::: warning 官方依据声明
补丁号、生命周期支持期限（EOL）、预览功能和许可协议会随时间演进。生产环境变更前，请始终以 [DuckDB 官方发布说明](https://duckdb.org/release_calendar) 为最终依据，勿仅凭文档标题推断当前最新版本。
:::
