# DuckDB 版本演进

DuckDB 遵循语义化版本发布。从 1.0 开始正式确立存储文件物理格式向前兼容承诺。

## 核心版本演进与关键里程碑

### DuckDB 1.1（2024 年 9 月）

**主要功能与架构演进：**

- 全面提升复杂多表连接与嵌套聚合的查询优化器规则
- 进一步优化对象存储（S3/GCS/Azure Blob）并行预读与元数据缓存

**工程影响与选型建议：**

> 进一步稳固单机列式分析性能。

### DuckDB 1.0（2024 年 6 月）

**主要功能与架构演进：**

- 存储格式稳定性保证（Storage Format Stability）：本地 `.duckdb` 文件格式承诺向前兼容
- 官方社区扩展（Extensions）安全签名校验机制
- 多线程并行哈希连接与 Out-of-Core 溢出排序全面成熟

**工程影响与选型建议：**

> 正式进入生产就绪（Production-ready）时代的里程碑。

### DuckDB 0.10（2024 年 3 月）

**主要功能与架构演进：**

- 引入固定大小二进制类型与增强的 SQL 方言解析
- 改进与 Apache Arrow 零拷贝内存交换规范

**工程影响与选型建议：**

> 1.0 前夕的核心稳定预备版本。

### DuckDB 0.9（2023 年 9 月）

**主要功能与架构演进：**

- 引入原生动态类型转推断机制与更完备的 JSON/Parquet 嵌套读写支持
- 重构多线程调度器以降低 CPU 线程争用

**工程影响与选型建议：**

> 极大提升了直接分析杂乱原始文件的容错度。

## 升级注意事项
- **1.0 之前创建的文件**：建议在 0.10 环境中通过 `EXPORT DATABASE` 导出为 Parquet/SQL，并在 1.0+ 环境中通过 `IMPORT DATABASE` 重新加载。
