# DuckDB 1.4 LTS

> **参考官方文档**：[DuckDB 官方发布说明](https://duckdb.org/release_calendar)  
> 本页依据正式 Release 与现有仓库版本证据，整理 DuckDB 1.4 LTS 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2025 年 9 月
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** DuckDB

## 核心变化

- 成为 DuckDB 首批明确采用一年社区支持周期的 LTS 系列
- 稳定扩展、存储格式和嵌入式分析能力
- 与后续当前功能版本并行维护

## 兼容与迁移

- 嵌入式升级应同时验证数据库文件、扩展 ABI 和语言客户端版本；LTS 与 Current 不能只按补丁号混用。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
duckdb --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
