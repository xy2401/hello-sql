# DuckDB 1.5

> **参考官方文档**：[DuckDB 官方发布说明](https://duckdb.org/2026/03/09/announcing-duckdb-150)  
> 本页依据正式 Release 与现有仓库版本证据，整理 DuckDB 1.5 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2026 年 3 月
- **维护状态：** 历史版本或兼容基线；实际维护状态以官方页面为准
- **产品线：** DuckDB

## 核心变化

- 重做命令行客户端并加入更友好的交互体验
- 加入 `VARIANT` 与内置 `GEOMETRY` 类型
- 缩小扩展体积并扩展 musl、Python CLI 等分发方式

## 兼容与迁移

- 1.5 是 Current 功能线而非 LTS；升级嵌入式应用时应锁定核心库、扩展和客户端的兼容组合。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
duckdb --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
