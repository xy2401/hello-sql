# Oracle Database 总览

Oracle Database 是大型金融、电信及核心 ERP 系统的工业级关系数据库，具备强大的多租户架构（CDB/PDB）、RAC 多活集群与高度精细的性能诊断体系（AWR/ASH）。

## 适用边界

适合 Oracle SQL、事务与企业数据库能力学习；部署、许可及镜像获取条件需按所选版本确认。

## 版本阅读范围

[完整版本目录](./version/)收录本仓库已有专题（如 oracle-ai-database-26ai、oracle-database-12c-r2、oracle-database-19c）。这些是教学与兼容性对照入口；运行环境的具体版本以安装页、工作台或采集证据为准。

## 推荐学习路线

[安装与环境](./install) → [核心概念](./core-concepts) → [命令行工具](./cli) → [完整版本目录](./version/)。先完成最小示例，再阅读版本差异。
