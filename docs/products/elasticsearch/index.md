# Elasticsearch 总览

Elasticsearch 是基于 Apache Lucene 构建的分布式搜索引擎与实时分析引擎，广泛应用于全文搜索、应用日志分析（ELK）与指标监控。

## 适用边界

适合全文检索与搜索聚合；索引可见性、映射和分片需要管理，不能直接替代业务事务数据库。
