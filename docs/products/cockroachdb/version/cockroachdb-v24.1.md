# CockroachDB v24.1

> **参考官方文档**：[CockroachDB 官方发布说明](https://www.cockroachlabs.com/docs/releases/)  
> 本页依据正式 Release 与现有仓库版本证据，整理 CockroachDB v24.1 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2024 年 5 月
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** CockroachDB

## 核心变化

**主要功能与架构演进：**

- 分布式 SQL 引擎针对复杂 JOIN 与窗口函数进行物理执行流水线优化
- 增强跨地域（Multi-Region）表的本地化生存策略（Survival Goals）

**工程影响与选型建议：**

> 跨国多数据中心部署性能进一步优化。

## 兼容与迁移

- 先完成备份、恢复演练和官方升级预检，不跨越未受支持的中间版本。
- 在副本、分片或集群环境按官方顺序滚动升级，并监控复制、延迟和错误日志。
- 同步核对客户端驱动、扩展、认证、配置参数与存储格式；回滚能力必须在升级前验证。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
cockroach version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
