# CockroachDB 总览

CockroachDB 是一款面向云原生时代打造的分布式 SQL 数据库，兼容 PostgreSQL 协议，以极强的故障自愈、多活容灾和默认严格的 Serializable（可串行化）事务隔离级别见长。

## 适用边界

适合需要分布式事务的关系数据；PostgreSQL 协议兼容不等于所有扩展、运维方式和性能行为都相同。
