# CockroachDB 版本演进

CockroachDB 采用年份与季度版本号（如 v24.1, v23.2），区分 Regular/LTS 维护周期。

## 核心版本演进与关键里程碑

### CockroachDB v24.1（2024 年 5 月）

**主要功能与架构演进：**

- 分布式 SQL 引擎针对复杂 JOIN 与窗口函数进行物理执行流水线优化
- 增强跨地域（Multi-Region）表的本地化生存策略（Survival Goals）

**工程影响与选型建议：**

> 跨国多数据中心部署性能进一步优化。

### CockroachDB v23.2（2023 年 11 月）

**主要功能与架构演进：**

- 引入物理存储空间自动重平衡（Auto-Rebalancing）限流控制，避免突发 I/O 挤占核心事务
- 支持更广泛的 PostgreSQL 扩展语法与驱动连接

**工程影响与选型建议：**

> 企业级大规模集群运维稳定性增强。

### CockroachDB v22.2（2022 年 11 月）

**主要功能与架构演进：**

- 重构底层存储引擎为 Pebble（基于 Go 开发的 LSM-Tree，全面替代 C++ RocksDB）
- 大幅降低 GC 停顿与跨 CGo 调用开销

**工程影响与选型建议：**

> 架构纯 Go 化的重大里程碑。

## 升级路径
- 必须严格遵循相邻版本升级路径（例如从 v22.2 -> v23.1 -> v23.2 -> v24.1），不可跳跃升级。
