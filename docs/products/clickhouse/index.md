# ClickHouse 概览

ClickHouse 是一款专为实时海量数据在线分析处理（Real-time OLAP）打造的高性能分布式开源列式数据库系统，能够在上千亿级数据规模下实现亚秒级 SQL 交互式查询。

## 核心技术点

- **MergeTree 存储引擎家族**：数据按物理排序键（`ORDER BY`）有序存储，后台自动执行多路合并（Merge）。
- **稀疏主键索引（Sparse Primary Index）**：默认每隔 8192 行记录一个索引标记（Mark），全量索引常驻内存。
- **极速 SIMD 向量化计算**：深度优化低级指令，单节点吞吐可达数千万行/秒。
