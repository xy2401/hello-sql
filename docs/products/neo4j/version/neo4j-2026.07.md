# Neo4j 2026.07

> **参考官方文档**：[Neo4j 2025–2026 Changes](https://neo4j.com/docs/operations-manual/current/changes-2025-2026/)

## 版本定位

- **发布时间：** 2026 年 7 月
- **维护状态：** 截至 2026-08-27 的当前日历版本线
- **平台基线：** Java 与支持平台要求以当期 Operations Manual 为准

## 核心变化

- Neo4j 从传统 5.x 版本线进入按年份与月份标识的发布节奏。
- 当前版本的功能、配置、安全、集群和运维变化由官方 `Changes in 2025–2026` 页面连续维护。
- 驱动、Cypher 行为、插件和管理命令必须与服务器版本一并核对，不能只验证数据库进程可启动。

## 不兼容与迁移

- 从 5.x 升级前先使用官方迁移和升级检查工具，处理已移除配置项、过程与插件接口。
- 核对 APOC、Graph Data Science、备份工具及各语言 Driver 的兼容矩阵。
- 集群升级需要按官方次序滚动操作，并在升级后验证路由、角色、索引和约束状态。

## 版本确认

```cypher
CALL dbms.components()
YIELD name, versions, edition
RETURN name, versions, edition;
```
