# Neo4j 版本演进

Neo4j 维护长期支持版（LTS，如 5.26 LTS）与月度快速迭代版本。

## 核心版本演进与关键里程碑

### Neo4j 5.23（2024 年 8 月）

**主要功能与架构演进：**

- Cypher 25 语法前瞻支持，增强图模式可变长度匹配性能
- 向量索引（Vector Index）深度整合进 Cypher 模式匹配

**工程影响与选型建议：**

> 图与向量知识图谱（GraphRAG）的核心首选。

### Neo4j 5.0（2022 年 10 月）

**主要功能与架构演进：**

- 引入自治集群（Autonomous Clustering），彻底告别历史 Causal Clustering 的复杂拓扑配置
- 多数据库（Multi-Database）管理与跨库查询大幅优化

**工程影响与选型建议：**

> 现代 Neo4j 集群与多租户架构基准。

### Neo4j 4.4 LTS（2021 年 11 月）

**主要功能与架构演进：**

- 企业级长期支持基准版本，提供稳定 Cypher 语法与存储格式
- 引入 Fabric 跨数据库分布式查询框架

**工程影响与选型建议：**

> 4.x 系列的终极稳定版。

### Neo4j 4.0（2020 年 1 月）

**主要功能与架构演进：**

- 原生多数据库支持（同一 DBMS 实例下运行多个独立图数据库）
- 细粒度基于角色的安全访问控制（RBAC）

**工程影响与选型建议：**

> 告别单实例单数据库历史，迈入企业级多数据库时代。

## 升级前运行配置迁移
```bash
neo4j-admin server migrate-configuration
```
