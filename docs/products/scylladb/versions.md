# ScyllaDB 版本演进

ScyllaDB 采用 C++ Seastar 架构，提供年度稳定版与企业级支持。

## 核心版本演进与关键里程碑

### ScyllaDB 6.0（2024 年 7 月）

**主要功能与架构演进：**

- 引入平板架构（Tablets）动态分片，支持细粒度跨 CPU 核心负载均衡
- 增强 Raft 元数据一致性与集群模式变更事务

**工程影响与选型建议：**

> 超大容量集群数据倾斜治理的重大突破。

### ScyllaDB 5.4（2023 年 11 月）

**主要功能与架构演进：**

- 基于 Raft 的强一致表结构变更（Schema Agreement）
- 优化 CDC（变更数据捕获）流式投递性能

**工程影响与选型建议：**

> 彻底消除了旧版 Gossip 同步表结构时的竞态冲突。

### ScyllaDB 5.0（2022 年 7 月）

**主要功能与架构演进：**

- 引入 I/O 调度器自动化调优，消除手工配置磁盘性能参数的繁琐步骤
- 支持虚拟节点（vnodes）动态缩容

**工程影响与选型建议：**

> 运维自动化与云原生弹性伸缩的重要基线。

## 滚动升级
- 按照官方版本路径逐台替换节点 rpm/deb 包并运行 `scylla-housekeeping`。
