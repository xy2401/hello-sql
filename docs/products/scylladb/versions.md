# ScyllaDB 版本演进

> **版本模型**：新版本采用年份版本号并提供明确的相邻版本升级指南；补丁升级与主线升级路径不同。

## 版本发布规律与生命周期

- **发布策略**：新版本采用年份版本号并提供明确的相邻版本升级指南；补丁升级与主线升级路径不同。
- **官方权威发布说明**：[查看 ScyllaDB 官方 Release Notes ↗](https://docs.scylladb.com/manual/stable/upgrade/index.html)

## 主流版本线与关键特性

### ScyllaDB 2026.2

**关键功能与演进：**

- 2026 年功能线继续演进
- 从 2026.1 有专门升级路径

**工程影响与选型建议：**

> 只按官方相邻版本指南滚动升级。

### ScyllaDB 2026.1

**关键功能与演进：**

- 年份版本基线
- 配置、监控和驱动需要同步核对

**工程影响与选型建议：**

> 升级前保存 system 与监控基线。

### 旧 6.x/2025.x 版本线

**关键功能与演进：**

- 版本命名和产品形态发生演进
- 跨代升级可能要求中间版本

**工程影响与选型建议：**

> 先确认支持策略和许可形态。

## 生产升级检查清单

跨版本或主版本升级时，建议按顺序核对以下事项：

1. **按节点完成 repair/备份与健康检查**
2. **核对驱动、CQL、system 表和管理工具**
3. **滚动升级期间监控 shard、streaming 和延迟**

::: warning 官方依据声明
补丁号、生命周期支持期限（EOL）、预览功能和许可协议会随时间演进。生产环境变更前，请始终以 [ScyllaDB 官方发布说明](https://docs.scylladb.com/manual/stable/upgrade/index.html) 为最终依据，勿仅凭文档标题推断当前最新版本。
:::
