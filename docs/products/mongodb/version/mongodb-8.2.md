# MongoDB 8.2

> **参考官方文档**：[MongoDB 官方发布说明](https://www.mongodb.com/docs/manual/release-notes/8.2/)  
> 本页依据正式 Release 与现有仓库版本证据，整理 MongoDB 8.2 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2025 年 9 月
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** MongoDB

## 核心变化

- 把 8.1 的增量改进带到 Atlas 与自托管发行版
- 改进初始同步、时序批量写入和查询多计划性能
- 调整孤儿文档清理期间的从节点读取终止行为，并增强查询统计

## 兼容与迁移

- 检查 Linux 内核兼容、`orphanCleanupDelaySecs` 默认值、地理索引生成和初始同步内存配置；先在分片与副本集拓扑演练滚动升级。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
mongod --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
