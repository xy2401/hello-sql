# MySQL 版本演进

> **版本模型**：MySQL 同时提供长期支持（LTS）与快速创新版本；生产平台通常固定 LTS，功能验证环境跟踪 Innovation。

## 版本发布规律与生命周期

- **发布策略**：MySQL 同时提供长期支持（LTS）与快速创新版本；生产平台通常固定 LTS，功能验证环境跟踪 Innovation。
- **官方权威发布说明**：[查看 MySQL 官方 Release Notes ↗](https://dev.mysql.com/doc/relnotes/mysql/8.4/en/)

## 主流版本线与关键特性

### MySQL 8.4 LTS

**关键功能与演进：**

- 稳定功能集合与长期修复窗口
- 从 8.0 升级涉及权限、参数和已移除能力

**工程影响与选型建议：**

> 多数生产新部署的基准版本线。

### MySQL 9.x Innovation

**关键功能与演进：**

- 更快交付新功能和移除项
- 升级频率与兼容验证成本更高

**工程影响与选型建议：**

> 适合提前验证未来 LTS，不宜无策略滚动到核心生产。

### MySQL 8.0

**关键功能与演进：**

- 窗口函数、CTE、原子 DDL 与数据字典奠定现代基线
- 生命周期与升级窗口必须纳入计划

**工程影响与选型建议：**

> 迁往 8.4 前先升级到最新 8.0 修复版本并运行 upgrade checker。

## 生产升级检查清单

跨版本或主版本升级时，建议按顺序核对以下事项：

1. **运行 MySQL Shell Upgrade Checker**
2. **检查 sql_mode、字符集与认证插件**
3. **演练复制拓扑混合版本和回退**

::: warning 官方依据声明
补丁号、生命周期支持期限（EOL）、预览功能和许可协议会随时间演进。生产环境变更前，请始终以 [MySQL 官方发布说明](https://dev.mysql.com/doc/relnotes/mysql/8.4/en/) 为最终依据，勿仅凭文档标题推断当前最新版本。
:::
