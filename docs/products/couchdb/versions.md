# Apache CouchDB 版本演进

CouchDB 采用 3.x 稳定分支，以 Erlang/OTP 为底层支撑。

## 核心版本演进与关键里程碑

### CouchDB 3.3（2023 年 3 月）

**主要功能与架构演进：**

- 引入基于 Java/Lucene 的 Nouveau 全新搜索引擎，替代旧版 Clouseau
- 大幅提升高频断网同步重连时的 Checkpoint 恢复吞吐

**工程影响与选型建议：**

> 全文检索与同步效率的现代化升级。

### CouchDB 3.0（2020 年 2 月）

**主要功能与架构演进：**

- 默认强制要求管理员密码与安全绑定网络端口，杜绝未授权访问风险
- 默认开启 Sharding 分片，限制单文档尺寸上限为 8MB

**工程影响与选型建议：**

> 3.x 现代企业级安全的基石。

### CouchDB 2.0（2016 年 9 月）

**主要功能与架构演进：**

- 首次合并 BigCouch 分布式集群分片代码，支持多节点水平扩展
- 引入 Mango 声明式 JSON 查询引擎

**工程影响与选型建议：**

> 从单机文档库迈向分布式集群的关键版本。

## 升级核对
- 检查 Erlang/OTP 运行库兼容性，升级后确保所有节点完成 `_replicator` 状态检查。
