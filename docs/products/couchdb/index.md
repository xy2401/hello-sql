# Apache CouchDB 总览

Apache CouchDB 是一款以高容错、纯 HTTP/JSON REST API 和离线双向复制协议为特色的文档型 NoSQL 数据库系统。

## 适用边界

适合 JSON 文档与复制同步；查询索引和冲突处理需要显式设计，跨文档关系查询不等同于关系型 JOIN。

[完整版本目录](./version/)收录本仓库已有专题（如 couchdb-2.0、couchdb-3.0、couchdb-3.3）。这些是教学与兼容性对照入口；运行环境的具体版本以安装页、工作台或采集证据为准。
