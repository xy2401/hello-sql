# SQLite 概览

> **定位**：零配置、单文件、进程内的关系数据库，是移动端、桌面端、边缘设备和本地优先应用的基础组件。

## 基础属性与架构形态

| 属性维度 | 规格与特性说明 |
| :--- | :--- |
| **数据模型** | 关系型 · 嵌入式 |
| **查询接口** | SQLite SQL；覆盖现代查询能力，但 ALTER TABLE、并发和类型规则与服务端数据库不同。 |
| **开源许可证** | Public Domain |
| **部署形态** | 应用内嵌，无独立服务器 · 移动、桌面、IoT 与浏览器 WASM · OPFS 可在浏览器持久化数据库文件 |

## 模型与查询语言

### 数据表达模型

关系表与动态类型亲和性；支持严格表、JSON 函数、FTS5、R-Tree。

### 查询交互方式

SQLite SQL；覆盖现代查询能力，但 ALTER TABLE、并发和类型规则与服务端数据库不同。

## 事务、索引与扩展机制

### 事务与一致性保障

- 完整 ACID
- 单写者、多读者模型
- WAL 改善读写并发但不把它变成分布式服务

### 索引与查询优化

- B-tree、部分索引、表达式索引
- FTS5 全文索引与 R-Tree
- 查询规划器可通过 EXPLAIN QUERY PLAN 检查

### 复制、分片与高可用扩展

- 垂直扩展到单机本地文件
- 复制与同步由宿主应用或外部系统完成
- 不适合多节点并发写入服务

## 适用边界与选型决策

### 适合场景

- ✅ 离线和本地优先应用
- ✅ 测试、缓存、配置与边缘数据
- ✅ 中小数据量的嵌入式业务

### 局限与约束

- ⚠️ 高并发写入受单写者约束
- ⚠️ 缺少内建用户与网络访问控制
- ⚠️ 分布式复制不是核心职责

::: tip 架构选型建议
数据属于单个设备或应用实例、运维成本必须接近零时优先 SQLite；多写节点服务应选择服务端数据库。
:::
