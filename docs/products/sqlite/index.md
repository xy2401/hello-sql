# SQLite 总览

SQLite 是一款极轻量、自包含、无独立服务器进程、零配置的嵌入式 SQL 数据库引擎，是移动端、桌面软件、边缘计算与浏览器端本地存储的事实标准。

::: tip 在线实验环境
可在 [SQLite 在线工作台](/playground/sqlite) 直接在浏览器中编写并执行 SQL 命令。
:::

## 适用边界

适合嵌入式、本地单机数据；浏览器实验使用 SQLite-WASM，文件持久化依赖 OPFS，不能代表多节点服务。
