# SQLite 版本演进

SQLite 采用稳定的 3.x 命名体系，保持跨平台单文件格式极强的向后与向前二进制兼容性。

## 核心版本演进与关键里程碑

### SQLite 3.46（2024 年 5 月）

**主要功能与架构演进：**

- 优化查询规划器中的临时 B-tree 内存开销
- 增强 PRAGMA optimize 与统计信息维护效率

**工程影响与选型建议：**

> 嵌入式与边缘环境的最新稳健版本。

### SQLite 3.45（2024 年 1 月）

**主要功能与架构演进：**

- 全新的 JSONB 二进制格式：将 JSON 解析速度与存储效率提升高达 2x
- JSONB 内部直接保存树形结构，避免每次操作重复反序列化

**工程影响与选型建议：**

> 大幅提升 SQLite 在嵌入式设备处理 JSON 数据流的吞吐。

### SQLite 3.38（2022 年 2 月）

**主要功能与架构演进：**

- 原生内置标准 JSON 运算符（`->` 与 `->>`），无需加载外部扩展库
- 查询优化器对包含大量 UNION ALL 的视图支持自动展开与常量折叠

**工程影响与选型建议：**

> JSON 成为 SQLite 核心标配能力。

### SQLite 3.37（2021 年 11 月）

**主要功能与架构演进：**

- 引入 `STRICT` 表语法（`CREATE TABLE t (...) STRICT;`）
- 强制进行列字段类型约束校验，违反数据类型时直接拦截报错

**工程影响与选型建议：**

> 打破了 SQLite 仅有动态弱类型的传统认知，满足强类型业务需要。

### SQLite 3.35（2021 年 3 月）

**主要功能与架构演进：**

- 原生支持 `ALTER TABLE ... DROP COLUMN` 语法直接删除列
- 支持标准 SQL 的内置数学函数（`sin`, `cos`, `log`, `sqrt` 等）
- 支持 `RETURNING` 子句返回插入或修改的数据

**工程影响与选型建议：**

> 极大改善了 Schema 变更与日常开发体验。

## 升级建议
- SQLite 库升级只需替换宿主语言绑定（如 Python sqlite3, Node.js better-sqlite3）或二进制文件，无需迁移底层 `.db` 文件。
