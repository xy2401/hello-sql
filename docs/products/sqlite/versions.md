# SQLite 版本演进

> **版本模型**：SQLite 使用连续 3.x 版本线并保持极强文件格式兼容；每次发布仍可能新增 SQL、函数和安全修复。

## 版本发布规律与生命周期

- **发布策略**：SQLite 使用连续 3.x 版本线并保持极强文件格式兼容；每次发布仍可能新增 SQL、函数和安全修复。
- **官方权威发布说明**：[查看 SQLite 官方 Release Notes ↗](https://sqlite.org/changes.html)

## 主流版本线与关键特性

### SQLite 3.50+

**关键功能与演进：**

- SQL 函数、查询规划和平台支持持续演进
- 绑定库版本可能落后于系统 SQLite

**工程影响与选型建议：**

> 先确认应用实际加载的库版本，而非只看系统命令。

### SQLite 3.45–3.49

**关键功能与演进：**

- JSON 与查询能力持续增强
- 部分边界行为和优化会变化

**工程影响与选型建议：**

> 对依赖 JSON、FTS 或特定计划的应用执行回归。

### SQLite 3.37+

**关键功能与演进：**

- STRICT 表提供可选严格类型
- 文件格式仍保持兼容

**工程影响与选型建议：**

> 可逐表引入严格模式，但要先清理历史脏数据。

## 生产升级检查清单

跨版本或主版本升级时，建议按顺序核对以下事项：

1. **记录宿主绑定实际版本和编译选项**
2. **运行 PRAGMA integrity_check 与迁移回归**
3. **验证 WAL、备份和异常退出恢复**

::: warning 官方依据声明
补丁号、生命周期支持期限（EOL）、预览功能和许可协议会随时间演进。生产环境变更前，请始终以 [SQLite 官方发布说明](https://sqlite.org/changes.html) 为最终依据，勿仅凭文档标题推断当前最新版本。
:::
