# SQLite 3.37

> **参考官方文档**：[SQLite 官方发布说明](https://sqlite.org/changes.html)  
> 本页依据正式 Release 与现有仓库版本证据，整理 SQLite 3.37 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2021 年 11 月
- **维护状态：** 历史版本或兼容基线；实际维护状态以官方页面为准
- **产品线：** SQLite

## 核心变化

**主要功能与架构演进：**

- 引入 `STRICT` 表语法（`CREATE TABLE t (...) STRICT;`）
- 强制进行列字段类型约束校验，违反数据类型时直接拦截报错

**工程影响与选型建议：**

> 打破了 SQLite 仅有动态弱类型的传统认知，满足强类型业务需要。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
sqlite3 --version
```
