# SQLite 版本演进

SQLite 采用稳定的 3.x 命名体系，保持跨平台单文件格式极强的向后与向前二进制兼容性。

## 版本索引

### [SQLite 3.53](./sqlite-3.53)

- **发布时间：** 2026 年 4 月
- **版本重点：** 重新交付并修正被撤回的 3.52 功能线。

### [SQLite 3.46](./sqlite-3.46)

- **发布时间：** 2024 年 5 月
- **版本重点：** 优化查询规划器中的临时 B-tree 内存开销。

### [SQLite 3.45](./sqlite-3.45)

- **发布时间：** 2024 年 1 月
- **版本重点：** 全新的 JSONB 二进制格式：将 JSON 解析速度与存储效率提升高达 2x。

### [SQLite 3.38](./sqlite-3.38)

- **发布时间：** 2022 年 2 月
- **版本重点：** 原生内置标准 JSON 运算符（- 与 -），无需加载外部扩展库。

### [SQLite 3.37](./sqlite-3.37)

- **发布时间：** 2021 年 11 月
- **版本重点：** 引入 STRICT 表语法（CREATE TABLE t (...) STRICT;）。

### [SQLite 3.35](./sqlite-3.35)

- **发布时间：** 2021 年 3 月
- **版本重点：** 原生支持 ALTER TABLE ... DROP COLUMN 语法直接删除列。

## 升级建议
- SQLite 库升级只需替换宿主语言绑定（如 Python sqlite3, Node.js better-sqlite3）或二进制文件，无需迁移底层 `.db` 文件。
