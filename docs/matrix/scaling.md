# 扩展、复制与分片

| 模式 | 解决的问题 | 代表产品 | 隐含成本 |
| :--- | :--- | :--- | :--- |
| 单机嵌入式 | 零运维、本地数据 | SQLite、DuckDB | 不提供共享并发服务 |
| 主库 + 读副本 | 读扩展、灾备 | PostgreSQL、MySQL | 复制延迟、读后写一致性 |
| 同步多副本 | 节点故障持续服务 | CockroachDB、TiDB | 写延迟和法定人数 |
| 应用分片 | 超越单节点写入 | 多数 OLTP 产品 | 路由、跨分片事务、再平衡 |
| 宽列分区 | 按键线性扩展 | Cassandra、ScyllaDB | 查询必须服从分区模型 |

扩展前先证明瓶颈来自数据库容量，而不是缺失索引、低效 SQL、连接风暴或不合理数据模型。
