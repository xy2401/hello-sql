# 索引、搜索与 JSON

| 结构 | 擅长 | 代表产品 | 主要代价 |
| :--- | :--- | :--- | :--- |
| B-tree / LSM 有序索引 | 点查、范围、排序 | 主流关系库、Cassandra 系 | 写放大、缓存与维护 |
| 倒排索引 | 全文、标签、相关性 | Elasticsearch、OpenSearch | 存储放大、刷新延迟 |
| 列式存储与 min/max 统计 | 大扫描和聚合 | DuckDB、ClickHouse、云仓库 | 点更新和短事务弱 |
| GIN / 多值索引 | JSON、数组、全文 | PostgreSQL | 写入与索引体积 |
| 图邻接结构 | 多跳遍历 | Neo4j | 分布式全图操作复杂 |
| 向量索引 | 相似度搜索 | pgvector、搜索引擎扩展 | 近似召回、内存与重建 |

JSON 字段应有清晰边界：频繁 JOIN、约束和排序的稳定字段通常值得提升为关系列；变化快、仅整体读写的边界对象更适合 JSON。
