# Database logo assets

These SVG files are local build assets. Product names and logos remain trademarks of their respective owners.

- PostgreSQL, MySQL, MariaDB, SQLite, DuckDB, ClickHouse, TiDB, Cockroach Labs, MongoDB, CouchDB, Redis, Cassandra, ScyllaDB, Elasticsearch, OpenSearch, Neo4j, InfluxDB, Timescale and SurrealDB marks are sourced from Simple Icons 16.28.0.
- Oracle Database and Microsoft SQL Server marks are sourced from Devicon 2.17.0.
- The Valkey mark is sourced from the Valkey project asset distributed by `@thesvg/icons` 3.3.1 and points back to valkey.io.
- PGlite uses the PostgreSQL mark because it packages PostgreSQL for the browser.
- Browser Database is based on browser standards rather than a vendor brand, so `browser.svg` is the neutral Hello SQL product mark; `indexeddb.svg` remains the runtime-engine mark.

SVGs must not contain scripts, remote references or runtime CDN dependencies.
