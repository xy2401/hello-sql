# Database logo assets

These SVG files are local build assets. Product names and logos remain trademarks of their respective owners.

- PostgreSQL, MySQL, MariaDB, SQLite, DuckDB, ClickHouse, TiDB, Cockroach Labs, Snowflake, BigQuery, MongoDB, CouchDB, Redis, Cassandra, ScyllaDB, Elasticsearch, OpenSearch, Neo4j, InfluxDB, Timescale and SurrealDB marks are sourced from Simple Icons 16.28.0.
- Oracle Database, Microsoft SQL Server and Amazon DynamoDB marks are sourced from Devicon 2.17.0.
- The Valkey mark is sourced from the Valkey project asset distributed by `@thesvg/icons` 3.3.1 and points back to valkey.io.
- PGlite uses the PostgreSQL mark because it packages PostgreSQL for the browser.
- IndexedDB is a browser standard rather than a branded database product, so `indexeddb.svg` is the neutral Hello SQL browser-database mark.

SVGs must not contain scripts, remote references or runtime CDN dependencies.
