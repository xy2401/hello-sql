# SurrealDB WASM 工作台

SurrealDB 是多模型数据库。本页使用官方 JavaScript SDK 和 WASM engine，临时模式连接 `mem://`，持久模式连接 `indxdb://`。

<DatabaseWorkbench engine="surrealdb" title="SurrealQL 多模型工作台" />

## 学习重点

- Record ID、文档字段和无固定表结构数据。
- SurrealQL 查询与关系遍历。
- 同一 API 在内存、IndexedDB 和远程服务之间的边界。

官方资料：[WASM Engine](https://surrealdb.com/docs/reference/javascript/engines/wasm)、[JavaScript SDK](https://surrealdb.com/docs/reference/javascript)。
